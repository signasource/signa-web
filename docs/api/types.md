# API types

> Responsibility: DTO shapes the web uses and where they come from.
> Update when: a DTO is added or changed here, or the API's DTO changes.
> Sources: src/lib/api/types.ts, src/lib/api/admin.ts, src/lib/api/metrics.ts; signa-api `organizations/dto/*`, `auth/dto/*`, `admin/dto/*`

Types live in `src/lib/api/types.ts`, camelCase (the client converts). They are **hand-mirrored** from the Java records — when the API changes a record, update the type here in the same change.

## Loose placeholders

None at the moment — every DTO the panel uses is typed. `BlockConfig` (`Record<string, unknown>`) is the one deliberately open type: each course-block type carries its own config (`src/lib/course-blocks.ts`).

## Admin sign editor types (`src/lib/api/admin.ts`)

| Web type          | API record                | Notes                                                                                                                                                                                                                                                          |
| ----------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AdminSign`       | `AdminSignResponse`       | Catalog row. `animationFormat: "glb" \                                                                                                                                                                                                                         | "mp4" \ | null`; `animationUpdatedAt`= last panel upload (null = imported);`lessonCount` = draft/published only |
| `AdminSignDetail` | `AdminSignDetailResponse` | `animationUrl` is the bucket **key** (`lsa/hola.glb`); load from `mediaUrl` (public, `?v=` cache-buster). `mediaAvailable` (false = the file does not exist), `lateralAnimationUrl`/`lateralMediaUrl` (side video of `.mp4` signs). `usages: AdminSignUsage[]` |

| `UpdateSignInput` | `UpdateSignRequest`       | Partial; `null`/omitted = unchanged; `youtubeUrl: ""` clears                                                                                                                                                                                                   |
